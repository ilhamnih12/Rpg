# Changelog

## 1.0.0 - 2026-08-20

### Added

- Next.js 14 App Router project with TypeScript strict mode.
- Tailwind CSS design system and shadcn/ui-inspired components.
- LocalStorage MVP authentication and persistence.
- Demo account `demo_warrior / demo123` with level 18 progress.
- Character creation with 8 avatars and 4 RPG classes.
- XP, level, stats, gold, streak, daily reward, and title systems.
- Inventory categories: Weapons, Armor, Potions, Badges.
- Loot rarity and crafting system.
- 50 achievements with rewards and title unlocks.
- 10 pet companions with unlock levels and feed action.
- Static fallback content: 250 questions, 30 monsters, 50 items.
- Gemini service with structured JSON prompts, rate limiting, cache, retry, and fallback.
- API routes for question generation, chat, hint, explanation, study plan, daily quests, and insights.
- AI Tutor Sage chat with markdown, voice input, favorite, share, and study plan generator.
- Quest system with custom AI quiz, daily quest, and story quest.
- Battle system with HP bars, combo, boss battle, potion use, and loot rewards.
- Dashboard analytics with charts, subject mastery, exam readiness, and activity heatmap.
- Leaderboard, friend system, guild creation/join, guild chat, and PvP quiz simulation.
- Mini-games: Quick Math Challenge, Memory Card Game, Word Search.
- Export/import progress.
- Comprehensive documentation files.

### Verified

- `npm run type-check` passes.
